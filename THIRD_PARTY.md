# Third-party components

Dependencies are installed by the package manager and are not vendored in this repository.

- [ezdxf](https://github.com/mozman/ezdxf): MIT; installs NumPy, fontTools, pyparsing and typing_extensions under their respective licenses.
- [Playwright](https://github.com/microsoft/playwright): Apache-2.0; optional browser development tests only.
- [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter): optional external proprietary application. Obtain it directly from ODA under its terms. No ODA binaries or license rights are redistributed here.

The example apartment was created specifically for this repository and is covered by the project's MIT license. It is not a customer floor plan.
